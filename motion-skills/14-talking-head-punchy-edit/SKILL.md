# 토킹헤드 클립 펀치 편집

## 시작 절차
입력을 받은 뒤(빠진 항목은 기본값 사용), 코드 전에 **초 단위 스토리보드**를 먼저 보여주고 확인받는다.

## 먼저 받을 입력
원본 영상 파일, 목표 길이와 비율(기본 9:16, 60초 이하), 자막 언어, 강조색, 배경음악(선택)

## 디렉션
엔진이 다르다: Whisper(또는 whisper.cpp)로 단어 단위 타임스탬프 전사 → 무음·말더듬·반복 구간을 잘라 점프컷 → 핵심 단어 강조 자막(단어별 팝, 강조색) → 말 내용에 맞는 그래픽(숫자 카운터, 아이콘, 밈 B롤 대신 HTML 그래픽)을 오버레이 → 줌 펀치(1.0→1.12)로 리듬. 그래픽 레이어는 seek(t) HTML로 투명 렌더 후 ffmpeg로 합성.

## 구조
1. 전사(JSON, 단어별 start/end) → 컷 리스트(무음 > 0.35s 제거, 필러 단어 제거)
2. 컷 리스트로 ffmpeg concat → 오디오 크로스페이드 10ms
3. 자막: 한 번에 2~4단어, 하단 1/3 위, 강조 단어 색 변경
4. 그래픽/줌 펀치는 문장 강세에 맞춰
5. 음악 -20dB 덕킹, 최종 -14 LUFS

## 금지
입모양과 어긋난 자막, 화면을 가리는 과한 이모지, 모든 컷마다 줌(리듬이 사라짐)

## 엔진 규칙
위 디렉션의 전용 엔진을 쓴다. 그래픽 오버레이가 필요하면 `scripts/motion.js`의 seek(t) 방식과 `scripts/render.mjs`를 함께 쓴다. 음악·효과음은 상업 이용 가능한 라이선스만, 최종 -14 LUFS.

## 렌더 전 체크리스트
자막 타이밍 오차 < 80ms · 잘린 곳에서 단어가 끊기지 않는가 · 얼굴이 자막/그래픽에 가려지지 않는가

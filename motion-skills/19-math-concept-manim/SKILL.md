# Manim 수학 개념 설명 영상

## 시작 절차
입력을 받은 뒤(빠진 항목은 기본값 사용), 코드 전에 **초 단위 스토리보드**를 먼저 보여주고 확인받는다.

## 먼저 받을 입력
개념(예: 도함수), 대상 수준, 길이(기본 3분), 내레이션 언어/목소리(edge-tts 음성명, 한국어 기본 ko-KR-SunHiJeongNeural)

## 디렉션
엔진이 다르다: **Manim Community** + edge-tts. 직관 → 예시 → 정의 → 응용 → 생각할 질문 순. 수식은 MathTex, 그래프는 Axes, 핵심 변화는 ValueTracker로 연속 애니메이션(예: 할선이 접선으로 수렴). 장면별 대본을 먼저 쓰고 TTS 길이를 측정해 `self.wait()`와 애니메이션 run_time을 맞춘다.

## 구조
1. 대본(장면별 문단) → edge-tts로 장면별 mp3 생성 → 길이 측정
2. 장면 클래스마다 run_time 합 = 음성 길이
3. 구성: 일상 예시(속도계) → 그래프 위 두 점 → 할선 기울기 → h→0 수렴 → 정의식 → 계산 예제 2개 → 생각할 질문
4. `manim -qh scenes.py` → ffmpeg로 장면 영상 + 음성 합치기

## 금지
음성과 어긋난 애니메이션, 설명 없이 등장하는 수식, 한 화면에 수식 3줄 초과

## 엔진 규칙
위 디렉션의 전용 엔진을 쓴다. 그래픽 오버레이가 필요하면 `scripts/motion.js`의 seek(t) 방식과 `scripts/render.mjs`를 함께 쓴다. 음악·효과음은 상업 이용 가능한 라이선스만, 최종 -14 LUFS.

## 렌더 전 체크리스트
각 장면 영상 길이 = 음성 길이(±0.1s) · 수식 렌더 오류 없음 · 예제 계산이 정확한가
